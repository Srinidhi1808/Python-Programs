# Python Programs

This repository contains five beginner-friendly Python programs created for learning and practice.

## Programs

1. **Simple Calculator** – Performs addition, subtraction, multiplication, and division.
2. **Even or Odd Checker** – Checks whether a number is even or odd.
3. **Prime Number Checker** – Checks whether a number is prime.
4. **Factorial Calculator** – Calculates the factorial of a number.
5. **Temperature Converter** – Converts Celsius to Fahrenheit and Fahrenheit to Celsius.

## Language Used
- Python

## Purpose
These programs help beginners understand basic Python concepts such as input/output, conditional statements, loops, and arithmetic operations.
